# Installation

MinimalSym is tested with **Python 3.12–3.13**, but should also work with **Python 3.9–3.13**.

## Requirements

- Python ≥ 3.9
- ASE
- NumPy
- Numba

To create and manipulate molecules as `Atoms` objects, install [ASE](https://wiki.fysik.dtu.dk/ase/):

```bash
pip install ase
```

---

## Install from pip

```bash
pip install minimalsym
```

---

## Install from source

```bash
git clone https://github.com/hyl-kibou/minimalsym.git
cd minimalsym
pip install -e .
```
