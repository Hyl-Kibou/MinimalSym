# API Reference

The MinimalSym API is divided into two categories.

---

## Public API

Stable high-level functions intended for normal usage.

- [`symmetrize`](public.md#symmetrize-operation)
- [Point group detection](public.md#point-group-detection)

See: [Public API](public.md)

---

## Internal helpers

Internal functions used by the symmetry algorithms.
These APIs are not guaranteed to remain stable.

See: [Internal helpers](internal.md)
